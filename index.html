第 1 章

数据

学习目标
理解数据类型与视觉通道，掌握数据整理和转换的基本方法。
实践成果
用 D3.js 加载新生 CSV，完成字段映射、分组与数据绑定。

知识要点

从 DeepSeek 合成新生数据出发，展开数据生成、DIKW、Stevens 测量尺度、Mackinlay 视觉通道、D3 数据变换与 Data-Join 三态。

  • DIKW 金字塔
  • Stevens 4 尺度
  • 8 个 D3 变换函数
  • Selection 三态

第 2 章

数据可视化流程

学习目标
理解数据、变换、映射与视图之间的关系，认识交互反馈。
实践成果
将新生数据按专业和班级组织为分类树，生成可交互的树形视图。

知识要点

Card 数据流模型、新生数据 → 分类树 → 树形列表的完整链路，Reingold-Tilford 布局、DOM 事件机制。

  • Card 模型
  • d3.rollup
  • Reingold-Tilford
  • 事件委托

第 3 章

色彩专题

学习目标
根据数据含义选择配色，理解颜色空间与色觉可访问性。
实践成果
生成图表配色，并用色觉缺陷模拟检查颜色是否容易区分。

知识要点

颜色模型 + colormap + Lab 色域 + 5 大色系 + 经典科研配色 + 对错案例 + 鲜艳+低饱和哲学生成器 + CVD 论文图测。8 小节，配色一站式。

  • 4 颜色空间 + CVD
  • Wong / Paul Tol
  • 5 大色系规则
  • 鲜艳+低饱和
  • CVD 论文图测

第 4 章

低维数据可视化

学习目标
理解坐标映射、曲线与等值线如何表达低维数据。
实践成果
用 Crime 数据比较坐标变换与曲线效果，探索等值线生成。

知识要点

Crime 数据坐标变换、10 种曲线拟合、Cleveland 45° 倾角、Marching Squares 等值线，共 5 小节。

  • 三层坐标变换
  • 10 种曲线
  • Cleveland 45°
  • Marching Squares

第 5 章

时序数据可视化

学习目标
识别时间数据的趋势、周期和事件关系，选择合适的表达方式。

▶️ 使用方式

🎓 课堂讲解

打开任一章节后，左侧选小节，顶部切换 讲解 / 代码 / 映射 / 演示 四个 tab，一边讲解、一边实时运行。

📖 学生自学

按章节顺序过完所有 ⭐ 关键点，每个关键点配有「为什么这么写」+「有什么坑」段落。

💻 教师备课时

每个章节有 1 套独立的 demo/ 子目录，可以单独跑、单独改、单独打包给学生。

📶 局域网使用

在课程目录运行 python -m http.server 8080 --bind 0.0.0.0，同一 WiFi 下可通过主机 IP 访问；交互演示仍需联网加载 D3.js。

ℹ️ 关于本课程

📖 理论来源

《可视化导论》、Mackinlay 1986、Stevens 1946、Cleveland 1984、Bostock D3 官方文档、Card 1999 数据流模型。

🎯 设计原则

案例为中心（不是理论为中心）。每个知识点都嵌入到用户的实践案例里，配 ⭐ 关键点解释 + 可运行演示。

🛠️ 技术栈

无需构建：纯 HTML + CSS + ES modules；交互演示通过 CDN 加载 D3.js v7。本地一条命令 python -m http.server 启动，无需 npm。

📦 数据集

新生与 Crime 等数据随各章 data/ 目录提供，通过本地 HTTP 服务读取。交互演示依赖在线 D3.js，当前不支持完整离线使用。

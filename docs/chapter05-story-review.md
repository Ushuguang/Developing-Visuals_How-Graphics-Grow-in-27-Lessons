## 原例为何保留

《侏罗纪公园》既有例子适合讲授“每角一条生命线、手工控制点、时间尺度、曲线生成、事件层”。电影角色与冲突也适合说明线的聚散。然而学生未看过电影时，需要先理解数据结构；原曲线同时出现容易让他们误以为 y 是人数、距离或算法自动推导的关系。

默认继续使用共享 `STORY_DATA` 同一个对象：5 角色、27 控制点（8/5/5/6/3）、127 分钟、两事件。角色与坐标均不重写。时间、控制点、datum、曲线、事件按原代码知识顺序逐项展开。

## 补充案例：校园小组协作

提供显式标注“构造教学微案例”的可选案例，原例仍是默认。

- 三位虚构同学各有 6 个控制点；0/5/10/15/20/30 分钟，共 18 点。
- 15 分钟交流进展，三个 y 值为 210/215/205，最大跨度 10；会合前与 20 分钟再分工后跨度更大。
- 两个事件：“会合”“再分工”。事件都在三角色的真实构造控制点时刻，便于核对 x 一致。
- y 是手工叙事布局，不是校园定位或真实学生跟踪；未读取任何个人数据。
- 用途是把陌生的电影剧情抽象成学生熟悉的协作情境，说明聚散编码的设计含义，随后可切回电影主例。

## 五步骤的可见反馈

每次绘图将 `data-stage` 写到场景和 SVG，供父任务浏览器逐按钮核对。图形当次直接形成终态，不依赖入场动画才可见。

| 步骤 | 真正出现/改变的图形 | 数值对应 / 反向操作 |
| --- | --- | --- |
| time | 水平时间轨道、各角色实际采样时刻、黄色粗垂线；此时没有角色关系曲线 | domain/range/实际 x 表；点刻度切时间，点采样切控制点 |
| points | 所选角色的全部控制点、浅色线性参考线、选中点高亮与原坐标标签 | 原 time/y 与 SVG x/y 逐行表；点击圆点或行按钮选择该点 |
| datum | 仅该角色一条真正 `.datum(character.points)` 的 path、整组虚线框、`Array(n) → datum → 1 path` 标记 | path 的 `__data__` 为原完整 points 数组；可核对 `data-role` / `data-bound-count`，不是每行一条 path |
| curve | 同一组点上的黑色虚线 `curveLinear` 与彩色 Catmull-Rom 同屏 | alpha 滑块立即更新真实 d；控制点与线性骨架不变，未说 alpha=0 等于线性 |
| events | 两事件红圈与标签、选中事件垂线、相关角色线与该时刻确实存在的采样点 | 原始角色 y / 事件锚点分开显示；共用 x 真实对齐。不存在该刻样本者不画伪交点 |

原例事件 78 分钟：共享 x 为约 **515.354331 px**；Alan 原 y=80，T-REX 原 y=130；其余角色无该分钟控制点，不插造采样。事件 48 分钟：Dilophosaurus 原控制点 y=320，事件锚点 y=335，二者不会被强行画成同一位置。

事件步可独立筛选角色/事件层；切入事件步骤或点击“定位会合/冲突时刻”会显示角色+事件，避免之前的筛选把关键图层藏掉。

## 课堂任务卡建议

1. **先预测**：同一条时间定位线为什么能同时穿过不同角色？先猜 t=78 的 x，再查看数表。
2. **找一条线的输入**：选择 T-REX，数控制点，再切 datum；解释为何 5 条记录只生成 1 条路径。
3. **让证据说话**：校园案例定位会合，读三角色 y；切回电影 t=78，看“同时间”是否真的等于“同布局位置”。
4. **曲线不是新数据**：固定角色与控制点，调 alpha=0/0.5/1。哪些对象变，哪些不变？虚线为何仍在原位？
5. **事件与线层分工**：隐藏事件圈时还能读哪些信息？缺少 Nedry 角色线意味着什么，能否凭空补一条？

## 生命周期与可访问性实现

- 角色、控制点、事件、案例、alpha 均为原生键盘控件。
- SVG 轨道点/路径/事件/刻度支持 Enter 与 Space；与表格行按钮反选同一预定义步骤，不执行页面代码文本。
- 视图重绘先 abort 上次视图 listener，再绑定新视图；关闭时取消场景 listener，清理自己的节点。
- 视图交互保留可对应图元的键盘焦点；图元跨阶段不再存在时回到可聚焦 SVG。
- 重置恢复原电影、第一角色/点/事件、alpha=0.5、完整事件图层、时间步骤。
- 此模块没有持续动画；共享器关闭动效或系统减少动态效果时仍可立即看到所有阶段终态。

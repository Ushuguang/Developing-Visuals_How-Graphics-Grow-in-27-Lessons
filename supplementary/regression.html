d3-regression 线性回归最小示例

10 个样本点, 用 d3.regressionLinear() 拟合一条直线。回归线定义域设为 [0, 100], 图中按数据范围裁剪显示。

代码

data = [{x: 8, y: 3}, {x: 2, y: 10}, {x: 11, y: 3}, {x: 6, y: 6}, {x: 5, y: 8},
       {x: 4, y: 12}, {x: 12, y: 1}, {x: 9, y: 4}, {x: 6, y: 9}, {x: 1, y: 14}];

const regression = d3.regressionLinear()
  .x(d => d.x)
  .y(d => d.y)
  .domain([0, 100]);

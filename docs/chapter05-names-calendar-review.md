## 3. 建议给教师的简短任务卡

这些任务只求文件内结果，不编造历史/天气/节假日解释：

1. **人名流行变迁**：分别定位三条曲线的文件内峰值，谁的峰值更早？原文件结果为 Marie 1971/5351，Jean 1979/5445，Camille 2003/5339。再固定1965与2000比较原频率差；不要称为人口占比。
2. **同年同窗比较**：把窗口改为1950–2000，核对三条线都剩51点，1965频率保持不变。说明裁切改变视野，不改变数据值。
3. **闰日与跨周**：定位2024-02-29，再比较2024-01-06与01-07；周日起点下后者进入下一列，周一起点下仍在同周。回答“为何不能只平移星期标签”。
4. **同数据不同问题**：展开同一温度文件的全年折线，对照日历。折线便于看全年高低，日历对齐星期与月份；仅凭图不能断言周末、春节或开学导致温差。
5. **找文件内异常**：定位原文件最高/最低温日期，返回色值步骤核对原记录与RGB色。当前文件极值为2024-02-07 −4°C、2024-06-28 22.6°C；这些是文件内值，不替代北京历史气象来源核验。

若后续要加春节/开学等注释，必须明确“教学示意事件”，不得当作原数据提供的事件或因果标签。本轮没有增加这类事件数据。
